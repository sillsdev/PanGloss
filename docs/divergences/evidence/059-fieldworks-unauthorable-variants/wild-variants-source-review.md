# Can these refusal variants occur in FieldWorks grammars?

_Source review of 2026-10-08. The metathesis verdict ("UNCLEAR") was settled afterwards by real-engine runs: see `metathesis-check.md`. The right-to-left rewrite and quantifier variants are worked in entries 058 and 065._

**Scope.** Static source review only; no build or runtime import was run. Sources: PanGloss `rust/crates/pg-foma/src/capability.rs` and `capability/variants.rs`; FieldWorks `Src/LexText/ParserCore/HCLoader.cs`; Machine `src/SIL.Machine.Morphology.HermitCrab/`. Local HC exports checked: `samples/data/sena-hc.xml`, `amharic-hc.xml`, `aweti-hc.xml`, and `indonesian-hc.xml`. “0 found” means no matching shape was verified by this review, not proof about every grammar.

- **right-to-left-rewrite.unlowerable** (`variants.rs:64`). Trigger: a right-to-left rewrite whose rule pattern cannot be reversed/lowered; exact gate: `if !detail.reversal_construction_attempted` (`capability.rs:2337`). PanGloss documents unsupported pattern shapes or no owning character table; an ambiguous disagreeing alpha-feature variable is one concrete shape. **FW:** author it in `PhRegularRule.Direction` with rule feature constraints and contexts; HCLoader maps direction and patterns at `HCLoader.cs:2003–24,2039–89,2318–43,2745–70`. **Machine:** yes for simple focus/replacement constraints and alpha variables; analysis reverses scan direction (`AnalysisRewriteRule.cs:28–38`, `FeatureAnalysisRewriteRuleSpec.cs:24–50`). Limitation: quantified focus/replacement nodes fail the checked simple-constraint cast; quantifiers are supported in environments (`PatternNodeCastExtensions.cs:13–38`). **Local:** 1 RTL rule, Aweti `aweti-hc.xml:1775–95`, but it is a plain natural-class rewrite; 0 confirmed refusals. **Verdict: AUTHORABLE BUT NOT SEEN LOCALLY** — the alpha-variable case is authorable and analyzable.

- **metathesis.left-to-right-unlowerable / metathesis.right-to-left-unlowerable** (`variants.rs:67–68`). The direction selects the ID; trigger for both is failure to construct the switch swap: `if !detail.swap_construction_attempted` (`capability.rs:2453–65,2504`); unsupported pattern slots include alpha/repeat, or missing table/bad switch indices (`capability.rs:822–44,2400–10`). **FW:** both directions are selectable on `PhMetathesisRule`; HCLoader maps direction and its structural description, including `PhIterationContext` to a quantifier (`HCLoader.cs:2103–48,2318–43`). **Machine:** direction-aware analysis exists (`AnalysisMetathesisRule.cs:17–30`), but an optional/repeated node in a switch group fails `CastToConstraints` (`AnalysisMetathesisRuleSpec.cs:54–63; PatternNodeCastExtensions.cs:13–38`). Other quantified groups’ import outcome is unverified; the analyzer does not preserve all HCLoader context groups in its reconstructed pattern (`AnalysisMetathesisRuleSpec.cs:20–49`). **Local:** 0 `<Metathesis…>` rules in the four exports. **Verdict for both: UNCLEAR** — FieldWorks can express the refused repeat shape, but Machine’s handling is incomplete/position-dependent.

- **circumfix.no-structural-route** (`variants.rs:71`). Trigger: a multi-part input drops some input material and fails the structural route: `if !detail.structural_composite_attempted` (`capability.rs:971–83,2700`). **FW:** standard circumfixes are generated from prefix + stem copy + suffix (`HCLoader.cs:1051–67,1273–1311`); process inputs/outputs are mapped at `1334–1420`. PanGloss’s only remaining no-route requires a dropping Reduplication/CircumfixSuffix role, but `CircumfixSuffix` is never produced (`emission_support.rs:248–51,469–71`); dropping non-peelable reduplication is structurally routed. **Machine:** generic affix-process analysis exists (`AnalysisAffixProcessRule.cs:10–25`), but the exact FieldWorks-generated shape cannot arise. **Local:** 0 exact no-route forms identified; Indonesian `mrule15` is a circumfix-plus-copy, routed structurally (see phonology research notes: `switch-candidates-phonology.md:486–98`). **Verdict: NOT AUTHORABLE IN FIELDWORKS (HC-XML-only)** — the required role/drop combination is not emitted by HCLoader.

- **reduplication.no-proposal-route** (`variants.rs:74`). Trigger: a true copy (the same input part is copied/modified at least twice) has neither a peel nor structural proposal: `if !detail.peel_attempted && !detail.structural_composite_attempted` (`capability.rs:935–65,2841`). **FW:** `MoAffixProcess.InputOS/OutputOS` can express copies (`HCLoader.cs:1334–1420`), but current rule loaders emit `AffixProcessRule`; the inflection loader says `TODO: use realizational affix process rules` (`976–79`). The principal no-route example is a reduplicating `RealizationalRule`, which FW’s HCLoader does not emit (`capability.rs:2732–54`). **Machine:** direct HC XML supports it: `XmlLanguageLoader.cs:392,947` and `AnalysisRealizationalAffixProcessRule.cs:10–26`. **Local:** 0 confirmed no-route copies: Indonesian has 3 true copies, including structurally routed circumfix `mrule15`; Amharic has 5 reduplication labels but 0 true copies; Sena 0; Aweti has 188 labels, not independently confirmed (`switch-candidates-phonology.md:139–45,498`; matching HC XMLs above). **Verdict: NOT AUTHORABLE IN FIELDWORKS (HC-XML-only)** — its needed realizational rule shape is not emitted by HCLoader.

- **quantifier.bounded-unlowerable / quantifier.unbounded-unlowerable** (`variants.rs:79–80`). Trigger for either: a rule with quantifiers whose whole pattern fails lowering: `if !detail.compile_attempted` (`capability.rs:3358–68`). Reasons include ambiguous disagreeing alpha variables, inverted finite bounds, nested/empty quantifiers, or no table; unbounded `max=-1` alone does not trigger it. The bounded ID means all quantifiers have finite maxima; the unbounded ID means at least one is unbounded (`capability.rs:904–19,3313–19`). **FW:** author in a `PhRegularRule` pattern/environment using `PhIterationContext.Minimum/Maximum` plus feature constraints; HCLoader maps bounds and plus/minus variable values (`HCLoader.cs:2003–24,2338–43,2745–70`; formula fields: `RuleFormulaVcBase.cs:214–46,421–26`). **Machine:** yes when the troublesome quantifier is in an environment; quantified focus/replacement is a known limitation (`AnalysisRewriteRule.cs:28–38; PatternNodeCastExtensions.cs:13–38`). **Local:** 0 exact unlowerable shapes verified. Valid quantifiers occur, including Indonesian `prule3` unbounded at `indonesian-hc.xml:935`. **Verdict for both: AUTHORABLE BUT NOT SEEN LOCALLY** — either boundedness class can accompany an authorable lowering failure, and environment quantifiers are analyzable.
