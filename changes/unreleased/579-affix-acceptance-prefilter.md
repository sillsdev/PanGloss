- Affix un-application now runs a register-free acceptance pass over each allomorph's automaton before the full traversal and skips the traversal when no accepting state is reachable, so parses of Dravidian-class grammars do far less work (Tamil: 3.9x to 4.5x fewer work steps over 23,682 words, 7.5x on the heaviest); analyses and their order are unchanged (#579). The pass holds the live states of a position in one machine word, allocates nothing, evaluates each constraint once per position and charges one work step per evaluation, so it costs about what the traversals it saves cost back on grammars where it rarely rejects: work steps Sena +0.6%, Swahili +1.6%, Mbugwe 0%, and a few small test words' `work_steps` rise 1% to 6%. An automaton of more than 64 states or constraints is not tested.
