- Affix un-application now runs a register-free acceptance pass over each allomorph's automaton before the full traversal and skips the traversal when no accepting state is reachable, so parses of Dravidian-class grammars do far less work; analyses and their order are unchanged (#579). The pass holds the live states of a position in one machine word, allocates nothing, evaluates each constraint once per position and charges one work step per evaluation. Windows instruction counters (5 repeats, 100 words per grammar): Tamil p145 heaviest 24 words -84.94%, Swahili -4.03%, Sena -0.30%, Mbugwe -0.24%. Linux work steps (deterministic counts, not time): Tamil 3.9x to 7.5x fewer, Swahili +1.6%, Sena +0.6%, Mbugwe 0%, and a few small test words' `work_steps` rise 1% to 6%. An automaton of more than 64 states or constraints is not tested: the pass answers true, so the traversal runs as before.
