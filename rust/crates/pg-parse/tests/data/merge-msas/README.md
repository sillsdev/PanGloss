# MergeMSAs end-to-end witness

`project.fwdata` is a hand-written, compact synthetic FieldWorks-shaped project. It contains a phoneme set for `ranna` and a morpheme-boundary marker (`+`), two parts of speech without affix templates, and one root entry with three `MoStemMsa` rows: an earlier Verb MSA with no sense, a later equal Verb MSA with the entry's sense, and a non-equal Noun MSA. The equality relation and representative choice are imported from the project records, not inserted into the snapshot by the test.

The `pg-parse` integration gate writes three temporary projects before import: the source with `MergeMSAs` absent (testing the FieldWorks default), and materialized explicit `true` and `false` values. Each run imports the `.fwdata`, compiles the snapshot, and parses a positive word, a valid no-analysis control, and an invalid-shape control. `expected.json` stores complete sorted `AnalysisIdentity` multisets and outcome flags.

The measured `ranna` identities are:

| Source setting | Effective value | `ranna` identity multiset |
| --- | --- | --- |
| absent (`default`) | `true` | `V42, N-e5` |
| explicit `true` (`enabled`) | `true` | `V42, N-e5` |
| explicit `false` (`disabled`) | `false` | `V42, V-e4, N-e5` |

`V42` is `{ "morphemes": ["00000000-0000-0000-0000-000000000042"], "rootIndex": 0, "category": "00000000-0000-0000-0000-00000000000c" }`; `V-e4` has the same Verb category and root index with morpheme `00000000-0000-0000-0000-0000000000e4`; `N-e5` has morpheme `00000000-0000-0000-0000-0000000000e5`, root index `0`, and Noun category `00000000-0000-0000-0000-00000000000b`. Both controls are unchanged in every run: `rann` has `no-analysis` with an empty multiset, and `?` has `invalid-shape` with an empty multiset. Every row has `capped`, `timed_out`, and `guessed` false. The JSON file carries the authoritative full rows.

Run the focused gate through the managed entry point:

```powershell
pwsh -NoProfile -File rust/tools/pg.ps1 -Mode test -Package pg-parse -TestTarget parse -Filter merge_msas_conformance
```

Measurement provenance: the parser implementation baseline was PanGloss commit `e2627c9aa2ec3e4f51550ced1c0b72941c470394`, and the checked-in source project has SHA-256 `60691e4cc2598f32c96e54be3a53080afd2bded54bd0027e0be9e3fb2f26a0de`.

Provenance is Rust-only: this fixture is not generated by LibLCM, and these expected parse identities have not been observed through the C# FieldWorks loader/parser. The project fixture is not a Machine/XAMPLE conformance fixture. The existing `tools/xample-projector parse-hc` adapter calls the two-argument non-merging `HCLoader.Load` path and does not read the project setting, so it cannot exercise this setting.

Verification on 2026-10-22: the focused gate passed. Temporarily replacing `MsaMerge::new`'s imported enable flag with `false` made the gate fail at the complete identity comparison: default/true each gained `V-e4`, while the disabled run and both controls stayed unchanged. The owner source was restored byte for byte. The final managed `-Mode check -Package pg-parse` passed, and `-Mode test -Package pg-parse -TestTarget parse` passed 118 tests with ten existing marked skips. This demonstrates regression sensitivity; the observations remain Rust-only.
